# ربط مكتبة goog بـChatGPT

## الهدف والنطاق

قراءة الكتب ومناقشتها داخل نافذة ChatGPT، مع الرجوع إلى مقاطع محددة من النسخة العربية وإمكانية فتحها في القارئ. المحادثة ينفذها ChatGPT نفسه؛ الخدمة لا تستدعي OpenAI API ولا تحتاج مفتاحًا أو رسوم استخدام نماذج مستقلة. اشتراك ChatGPT وإتاحة الاتصالات المخصصة في حساب المستخدم منفصلان عن مجانية الاستضافة.

## البنية والتكلفة

القارئ الحالي: GitHub Pages. جسر القراءة: Cloudflare Workers على الخطة المجانية بعنوان workers.dev، مع بيانات وفهارس ثابتة على GitHub Pages مبنية من كتب الفهرس فقط. لا حاجة إلى قاعدة بيانات أو تخزين مدفوع أو نطاق خاص أو خادم دائم التشغيل. حدود الخطة الحالية 100 ألف طلب يوميًا و10ms CPU للطلب، ولذلك يبنى فهرس البحث مسبقًا، وتقسم الملفات لتقليل القراءة والتحليل في كل طلب. لا يمكن ضمان عدم تغيير المزود سياسته مستقبلًا. لا تُفعّل ترقية مدفوعة تلقائية.

## مراحل التنفيذ ومعايير القبول

1. **مصادر الكتب:** بناء قابل للتكرار من books/catalog.json؛ استخراج النص والهيكل دون الصور المضمنة؛ تقسيم حسب الفصل والفقرة؛ بصمة للمحتوى؛ فصل الصفحات غير المترجمة والملاحظات في الوصف. المعيار: كل مرجع يعود إلى كتاب وفصل ومقطع موجودين، ولا يتسرب ملف خارج الفهرس.
2. **خادم MCP:** JSON-RPC عبر POST /mcp؛ اكتشاف الأدوات، قراءة المكتبة، فهرس كتاب، قراءة جزء من فصل، البحث، وجلب مقطع محدد. صفحات النتائج وحدود المدخلات والردود؛ أخطاء مفهومة؛ توصيف readOnlyHint؛ إرشادات التعامل مع الكتاب كمصدر غير موثوق للتعليمات، والتمييز بين كلام المؤلف والتحليل. المعيار: اجتياز عميل MCP فعلي واختبارات الطلبات المعطوبة والمراجع والبحث العربي.
3. **القارئ:** دعم روابط الكتاب/الفصل/الفقرة، وزر «ناقش في ChatGPT» يعرض سياق القراءة المحدد ويمكن نسخه وفتح ChatGPT. الرابط لا يرفق نص الكتاب تلقائيًا ولا يضمن فتح محادثة متصلة؛ المستخدم يستدعي تطبيق المكتبة داخل ChatGPT. المعيار: اختبار هاتف وحاسوب، العودة للمقطع الصحيح، وعدم تعديل التقدم من الخدمة.
4. **النشر المجاني:** تثبيت أدوات نشر مثبتة الإصدار، بناء البيانات، حساب Cloudflare مجاني، نشر الخدمة، تسجيل عنوان /mcp في ملف الإعداد العام بعد نجاحه، واختبار endpoint الحقيقي. المعيار: HTTPS، initialization وtools/list وقراءة وبحث من العنوان المنشور.
5. **الربط بحساب ChatGPT:** إضافة اتصال MCP مخصص بلا مصادقة لأن مصدره كتب عامة أصلًا، تثبيت الاتصال، مناقشة فصل وتجربة سؤال يتطلب البحث وعرض المراجع. إتاحة الخيار تعتمد على حساب المستخدم/مساحة عمله. المعيار: نداء أداة حقيقي من نافذة ChatGPT، لا الاكتفاء بنجاح اختبار محلي. هذه الخطوة تحتاج جلسة المستخدم وتفاعله إذا طلب تسجيل دخول أو موافقة اتصال.
6. **التسليم والصيانة:** تعليمات تحديث المكتبة والنشر والتحقق والتراجع. إعادة بناء البيانات عند تعديل الكتب. حفظ المصادر في المشروع ورفع تغييرات الربط إلى مستودعه بعد الاختبار. توثيق واضح لأي خطوة لم تُنفذ بعد.

## أدوات القراءة

- list_books: الكتب المتاحة وأوصاف نطاقها وبصمات النسخ.
- get_book: الفصول ومراجعها وأعداد المقاطع.
- read_chapter: قراءة متتابعة محدودة مع مؤشر الجزء التالي.
- search_books: بحث عربي/إنجليزي مطبع، مع خيار تحديد كتاب، وأفضل المقاطع ومراجعها؛ بحث لفظي وليس بحثًا دلاليًا.
- fetch_passage: النص الدقيق للمقطع ومصدره والرابط إلى القارئ.

## حدود الخصوصية والتشغيل

المدخلات للبحث والقراءة فقط، لا أدوات كتابة ولا قراءة من جهاز المستخدم ولا الوصول إلى Firebase أو الملاحظات أو الحسابات. الخدمة العامة تعيد الكتب الموجودة أصلًا في الموقع العام؛ لا تستخدم للكتب الخاصة. لا يسجل التطبيق الأسئلة أو IP ولا يحتاج أسرارًا. قد يحتفظ مزود الاستضافة بسجلات تشغيل وفق سياسته. يمنع fetch لعناوين يحددها المستخدم، وتمنع المسارات غير المعروفة. الطلبات والنتائج محدودة الحجم. عند تجاوز الخطة المجانية يتوقف الطلب بدل اختيار خطة مدفوعة.

## ما يؤجل

المزامنة الشخصية التلقائية، الملاحظات الخاصة، وإظهار واجهة قارئ داخل المحادثة: ليست ضرورية لقراءة الكتب ومناقشتها، وتحتاج تصميم هوية وصلاحيات مستقلًا. سياق الفقرة ينقله المستخدم صراحة بالزر، فلا تنقل بيانات القراءة الشخصية تلقائيًا إلى خدمة عامة.
