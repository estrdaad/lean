# خدمة مكتبة goog لـChatGPT

خادم MCP للقراءة فقط، يعمل على Cloudflare Workers المجاني دون OpenAI API. الكتب والفهرس المبني موجودة في GitHub Pages. يقرأ الخادم ملفات ثابتة من مصدر مضبوط، ولا يقبل URL من المستخدم. لا يدخل إلى Firebase ولا موضع القراءة أو الملاحظات. نقل السياق من القارئ صريح بواسطة المستخدم.

## البناء والاختبار

من هذا المجلد:

```sh
npm ci
npm run build
npm test
```

يبني `tools/build-chatgpt-library.py` مجلد `chatgpt-data/` من الكتب المسجلة في فهرس المشروع فقط. يُنشر هذا المجلد مع GitHub Pages. لا تُضمّن الصور الثنائية؛ تبقى في القارئ الأصلي. لكل نسخة كتاب بصمة مختلفة لتجنب خلط فهرس قديم بنص جديد. لا تحذف مجلد نسخة قديمة من الاستضافة أثناء بقاء طلبات تستخدمها؛ تحديث Pages الكامل يحل محل البيانات ويتولى الخادم إعادة قراءة الفهرس خلال دقيقة.

## النشر على الخطة المجانية

```sh
npx wrangler login
npx wrangler deploy
node scripts/verify.mjs https://goog-reader-mcp.estrdaad-reader.workers.dev/mcp
```

يمكن أيضًا نشر `worker.mjs` من موصل Cloudflare بإرساله كـES module، مع main_module وcompatibility_date الموجودين في wrangler.jsonc، وplain-text bindings لـREADER_URL وDATA_ORIGIN. لا تُخزن رموز الحساب في المشروع. لا يحتاج الخادم حزم npm وقت التشغيل. تبعيات التطوير للنشر وعميل الاختبار فقط.

بعد نجاح التحقق، حدث `chatgpt-config.json` بالعنوان وحالة verified، ثم انشر القارئ. صفحة `chatgpt-setup.html` تشرح ربط الحساب. نجاح الخادم لا يثبت تثبيت الاتصال داخل ChatGPT؛ يجب إكماله وتجربة نداء أداة من المحادثة.

## التحديث والتراجع

عند تحديث كتاب: أعد البناء والاختبار ثم انشر ملفات البيانات مع نسخة القارئ المقابلة. روابط block مرتبطة بنسخة النص الحالية، وقد تتغير عند تحديثه. الإحالة تحتوي version؛ أداة fetch_passage ترفض بصمة قديمة بدل خلط النصوص. للتراجع: استعد commit سابقًا يحتوي الكتب وبياناتها والقارئ معًا، وأعد نشر worker إذا تغير الكود. لا تغير كتابًا أو تحذف بيانات نسخته بمعزل عن بيانات البحث.

## حدود الخدمة

100 ألف طلب/يوم و10ms CPU/طلب على الخطة المجانية الحالية. تقسيم الفهرس إلى 256 ملفًا لكل كتاب يقلل التحليل؛ ثلاثة مصطلحات للبحث وأربع نتائج كحد أقصى. البحث لفظي، ليس استرجاعًا دلاليًا. الاستعلام العام يبحث الكتب الخمسة الأولى؛ حدد bookId للوصول إلى أي كتاب يضاف لاحقًا. لا توجد كتابة أو جلسات أو مخزن دائم أو ترقية مدفوعة تلقائية. الطلبات مجهولة لأن محتواها عام؛ لا تنشر كتبًا خاصة بهذه البنية.

يدعم النقل stateless Streamable HTTP JSON، مع initialize وping وtools/list وtools/call، وserver/discover للتوافق. لا يحتفظ بجلسة SSE أو معرف جلسة. client الرسمي لـMCP ضمن الاختبارات هو معيار التوافق. منع Origin غير موثوق وحجم طلب 32KB وحدود المدخلات يمنعان الاستعمال غير المنضبط؛ لا يُعد هذا نظامًا لمقاومة هجوم موزع، وتظل حدود Cloudflare سارية.
