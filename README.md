# الشركة الناشئة المرنة — إريك ريس

قارئ ويب عربي يعرض الكتاب صفحةً صفحة من ملف PDF الأصلي. تتضمن الصفحة الرسوم والجداول كما تظهر في المصدر، مع رابط للملف الأصلي.

## الملفات

- `index.html`: صفحة القراءة.
- `book-pages/`: صور الصفحات الـ150 المستخدمة في القارئ.
- `lean-startup.pdf`: ملف الكتاب الأصلي.

افتح `index.html` في متصفح حديث، أو انشر محتويات المستودع على GitHub Pages.
