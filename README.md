# الشركة الناشئة المرنة — إريك ريس

قارئ ويب عربي يعرض كتاب **The Lean Startup** كاملًا من ملف PDF المرفق. يعرض الملف الأصلي صفحاته ورسومه وجداوله كما هي، مع إمكان استخدام أدوات قارئ PDF للتنقل والتكبير والبحث.

## الملفات

- `index.html`: صفحة القراءة التي تُعرض عند فتح الموقع.
- `lean-startup.pdf`: ملف الكتاب المضمّن في الموقع.

## التشغيل

افتح `index.html` في متصفح حديث، أو انشر محتويات المستودع على GitHub Pages. يفتح زر «فتح ملف الكتاب» ملف PDF مباشرة في تبويب مستقل.
