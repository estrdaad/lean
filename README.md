# الشركة الناشئة المرنة — إريك ريس

نسخة ويب منسقة من الصفحات المتاحة في ملف الكتاب (1–150). تحافظ الصفحة على واجهة القارئ العربية الأصلية، بما فيها الفهرس وأدوات الخط وأنماط الألوان والخطوط المضمنة، وتعرض نص الكتاب بفقرات وعناوين HTML مع الرسوم والجداول المرفقة.

## الملفات

- `index.html`: صفحة القراءة وواجهة القارئ.
- `lean-startup.pdf`: ملف المصدر الأصلي.
- `book-figures/`: غلاف الكتاب ورسومه وجداوله.

افتح `index.html` في متصفح حديث أو انشر محتويات المستودع على GitHub Pages.
