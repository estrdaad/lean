# الشركة الناشئة المرنة — إريك ريس

نسخة قراءة عربية تضم محتوى النسخة الإنجليزية الكاملة ذات 296 صفحة، بما فيها الفصول الختامية والحواشي والمراجع. نُقّحت الترجمة بالمقارنة مع الأصل لتوضيح المعنى وتوحيد المصطلحات، مع تنظيم الفقرات والعناوين والجداول في HTML.

تضم واجهة القارئ فهرسًا وأدوات قراءة مخفية داخل زر عائم، وخطوطًا عربية مضمنة، وأنماطًا فاتحة وداكنة ومريحة للعين. استُخدم غلاف النسخة الإنجليزية ولوحة ألوان مستوحاة منه. تتيح إحالات الحواشي المربوطة الانتقال إلى المرجع والعودة إلى موضع القراءة.

## الملفات

- `index.html`: صفحة القراءة وواجهة القارئ.
- `lean-startup.pdf`: ملف المصدر العربي للصفحات الأولى (1–150).
- `book-figures/`: غلاف الكتاب ورسومه وجداوله.

افتح `index.html` في متصفح حديث أو انشر محتويات المستودع على GitHub Pages.
