# مكتبة القراءة

قارئ كتب عربي بصفحات أفقية، وخطوط مضمنة، وأنماط فاتحة وداكنة ومريحة للعين. تضم المكتبة كتاب **الشركة الناشئة المرنة — إريك ريس** بترجمته المنقّحة ورسومه وحواشيه.

## الاستخدام

افتح `index.html` أو شغّل الموقع على خادم محلي أو GitHub Pages. افتح **المكتبة** من شاشة الغلاف أو قائمة أدوات القراءة لإضافة كتب JSON، وفتحها وتصدير كتاب أو المكتبة كاملة. يمكن تجربة الاستيراد باستخدام `books/example-book.json`.

موضع القراءة وعلامة الصفحة المحفوظة مستقلّان لكل كتاب. لحفظ الصفحة أو إزالة علامتها استخدم «حفظ الصفحة» في قائمة الأدوات. يظهر زر العودة إلى الصفحة المحفوظة وزر مستقل لإزالة العلامة. لا يُضاف أي دبوس أو تمييز إلى النص. تحفظ الكتب المستوردة على الجهاز والمتصفح الحاليين. يدعم الاستيراد صيغة الكتاب أو المكتبة الموثقة في [BOOK-FORMAT.md](BOOK-FORMAT.md)، ويضم التصدير الصور والنصوص والتنسيقات دون الحاجة إلى ملفات خارجية للكتاب.

## تنظيم المشروع

- `index.html`: هيكل واجهة القارئ والمكتبة.
- `book-library.js` و`book-library.css`: المكتبة وصيغة الكتب والتخزين والاستيراد والتصدير.
- `libby-reader.js` و`libby-reader.css`: أدوات القراءة والتقليب والبحث والدبابيس.
- `books/lean-startup.json`: محتوى الكتاب المرفق، منفصل عن الواجهة.
- `books/good-to-great-revised.json`: النسخة العربية المنقحة من «من جيد إلى عظيم» لجيم كولينز، متاحة تلقائيًا في المكتبة عبر `books/catalog.json`، مع الصور والفهرس والحواشي.
- `books/good-strategy-bad-strategy-ar.json`: ترجمة متن «الاستراتيجية الجيدة والاستراتيجية السيئة» لريتشارد روملت، بفصوله الثمانية عشر ورسومه الأصلية، متاحة من المكتبة عبر `books/catalog.json`.
- `books/bundled-book.js`: نسخة بديلة لفتح التطبيق مباشرة من الملفات.
- `fonts.css` و`book-original.css`: الخطوط وتنسيقات المحتوى المشتركة.
- `book-figures/` و`lean-startup.pdf`: الأصول وملف المصدر السابق.

لتعديل الكتاب المرفق، عدّل JSON ثم حدّث نسخة التشغيل المباشر باستخدام `python3 tools/update-book-bundle.py`.

## أدوات التصميم

أيقونات Lucide وتحديد موضع قائمة الأدوات بواسطة Floating UI مضمنة محليًا. تفاصيل المصادر والإصدارات والتراخيص في [THIRD-PARTY.md](THIRD-PARTY.md). يعيد القارئ حساب الصفحات بعد استقرار أبعاد الشاشة ويحفظ موضع النص عند التدوير أو تغيير الخط.

## مزامنة تقدم القراءة

تبقى الكتب في GitHub ويحدد `books/catalog.json` الكتب المتاحة في المكتبة. لإضافة كتاب لجميع الأجهزة، أضف ملفه إلى `books/` ثم أضف معرّفه وعنوانه ومؤلفه ومساره إلى الفهرس. تُحمّل ملفات الكتب عند فتحها؛ الاستيراد من الجهاز يبقى محليًا.

يحفظ `reader-sync.js` موضع النص وعلامة الصفحة في مشروع Firebase `gog-reader-20261012`، قاعدة `reading-progress` في الدمام (`me-central2`). لا يوجد تسجيل دخول: التقدم مشترك لجميع من يفتحون التطبيق، بحسب اختيار صاحب المشروع. مسار كل سجل هو `readingProgress/{bookId}`. يمكن لمن يعرف إعداد Firebase قراءة هذه السجلات وتعديلها؛ قواعد البيانات تتحقق من بنية التقدم فقط. الكتب ومحتواها لا تُرفع إلى Firebase.

تعمل المزامنة عبر HTTP/HTTPS، بما في ذلك GitHub Pages. عند انقطاع الشبكة تُحفظ التغييرات محليًا وتُعاد المحاولة. تُحسم التعديلات المتعارضة بحسب وقت تعديل الجهاز، لذا ينبغي أن تكون ساعات الأجهزة مضبوطة تلقائيًا. موضع النص يعيد تحديد الصفحة بحسب أبعاد الشاشة والخط، وتبقى إعدادات العرض محلية لكل جهاز.

نُشرت قواعد Firestore بعد الموافقة الصريحة على الوصول دون مصادقة. لإعادة نشر الإعداد:

```sh
npx -y firebase-tools@latest deploy --only firestore --project gog-reader-20261012
```

`firebase-config.js` يحتوي إعداد Web SDK العام، وليس بيانات اعتماد لخادم. إعداد Hosting اختياري؛ الموقع يستطيع البقاء على GitHub Pages.

للتحقق من سلوك المزامنة: `node --test tests/reader-sync.test.cjs`.

## القراءة وPDF

تفتح بطاقة الكتاب شاشة الغلاف، وفي أسفلها زر متابعة واحد. أدوات القراءة زر عائم أعلى النص بشفافية 95٪، ويظهر عند فتحه أو التركيز عليه بلوحة المفاتيح. عند التقليب، يظهر تقدم الفصل بتلاشٍ 250 مللي ثانية، وثبات 500 مللي ثانية، واختفاء 250 مللي ثانية. تحترم الواجهة تفضيل تقليل الحركة.

يبدأ حجم الخط بـ21 بكسل على أجهزة اللمس و18 بكسل على أجهزة الماك، ويُحفظ أي تعديل في المتصفح نفسه دون مزامنته إلى الأجهزة الأخرى.

زر **PDF** في بطاقة الكتاب يفتح إعداد الخط والحجم والتباعد والورق والهوامش، وبدايات الفصول والصفحات المختارة. تعرض المعاينة التنسيق؛ ثم يفتح **حفظ PDF** نافذة الطباعة لاختيار الحفظ بصيغة PDF. يعتمد الإخراج على طباعة المتصفح للحفاظ على النص العربي والرسوم المتجهة، وتبقى إعدادات تصدير PDF منفصلة عن إعدادات القراءة.

لاختبار الواجهة وتصدير PDF تجريبي، ثبّت Playwright وشغّل خادمًا محليًا على المنفذ 8087 ثم `node tests/reader-ui.cjs`. يتطلب الاختبار Chrome على macOS، ويحفظ المخرجات التجريبية في `/private/tmp/gog-reader-qa`.

## ستيف جوبز

`books/steve-jobs-ar.json` نسخة عربية قيد الاستكمال تضم الصفحات التمهيدية والمقدمة والفصول 1–12، مع صور البداية. تُضاف تلقائيًا إلى مكتبة القارئ عبر `books/catalog.json` وتستخدم خطوطه وأدوات القراءة نفسها.

## المناقشة داخل ChatGPT

خدمة MCP في `chatgpt-bridge/` تتيح لـChatGPT قراءة كتب المكتبة العامة والبحث فيها مع مراجع إلى النص. خطة التنفيذ في [docs/CHATGPT-INTEGRATION-PLAN.md](docs/CHATGPT-INTEGRATION-PLAN.md)، وخطوات المستخدم في [chatgpt-setup.html](chatgpt-setup.html). زر «ناقش في ChatGPT» ضمن أدوات القراءة يجهز سياقًا ينسخه المستخدم صراحة إلى المحادثة.

عند تعديل كتاب أو فهرس المكتبة، شغّل `python3 tools/build-chatgpt-library.py` وانشر مجلد `chatgpt-data/` مع القارئ. خدمة Cloudflare للقراءة فقط، ولا تحتاج مفتاح OpenAI API، ولا تتصل بمواضع القراءة أو الملاحظات. نجاح نشرها لا يعني تثبيت الاتصال في حساب ChatGPT تلقائيًا.
