التكلفة والبيانات

الربط لا يستدعي OpenAI API ولا يحتاج مفتاحًا. يستخدم حدود Cloudflare Workers المجانية، وتبقى شروط حساب ChatGPT منفصلة. الخدمة للقراءة فقط، ولا تتصل بتقدم القراءة أو الملاحظات في Firebase. البحث لفظي مطبّع للعربية؛ قد تحتاج تجربة مصطلحات قريبة.

لا توجد خدمة تضمن مجانية دائمة بلا تغيير. عند بلوغ حدود الخطة المجانية قد تتعذر الطلبات؛ لا يفعّل هذا المشروع ترقية مدفوعة.
